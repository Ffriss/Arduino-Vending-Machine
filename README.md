# Venduino: ตู้จำหน่ายสินค้าอัตโนมัติ

ตู้ขายสินค้า 4 ช่อง (A–D) ทำงานด้วย Arduino UNO 2 บอร์ดร่วมกับ Raspberry Pi ลูกค้าหยอดเหรียญ เลือกสินค้า แล้วกดยืนยัน บอร์ดจ่ายสินค้าจะหมุนเซอร์โวจนเซนเซอร์ IR ตรวจพบว่าสินค้าตกลงมาจริง ระบบจึงหักเงิน ส่วนผู้ดูแลดูยอดขายและจัดการสต็อกผ่าน Dashboard บนเว็บได้

วิชา 240-319 Embedded System Developer Module

## ภาพรวมระบบ

```
┌──────────────────┐   USB Serial    ┌──────────────────┐   Serial (D3/D4)   ┌──────────────────┐
│   Raspberry Pi   │ ◄─────────────► │   บอร์ดควบคุม     │ ◄────────────────► │  บอร์ดจ่ายสินค้า   │
│ Flask + SQLite   │                 │   (arduino_1)    │                    │   (arduino_2)    │
│ Dashboard :5000  │                 │ เหรียญ ปุ่ม LCD   │                    │ เซอร์โว 4 ตัว + IR │
└──────────────────┘                 └──────────────────┘                    └──────────────────┘
```

| ส่วน | หน้าที่ |
| --- | --- |
| **บอร์ดควบคุม** (`arduino_1`) | รับเหรียญ อ่านปุ่ม แสดงผลบนจอ LCD ตรวจว่ามีเงินและสต็อกพอ สั่งให้บอร์ดจ่ายสินค้าทำงาน และรายงานผลการขายไปที่ Pi |
| **บอร์ดจ่ายสินค้า** (`arduino_2`) | รับคำสั่ง A–D แล้วหมุนเซอร์โวของช่องนั้นจนกว่า IR จะพบสินค้า จากนั้นตอบกลับว่า `Y` (สำเร็จ) หรือ `N` (ไม่สำเร็จ) |
| **Raspberry Pi** (`vending_machine`) | เก็บราคา สต็อก และประวัติการขายในฐานข้อมูล SQLite และเปิด Dashboard ให้ผู้ดูแล |

## โครงสร้างไฟล์

```
vending-machine/
├── arduino_1/
│   └── arduino_1.ino        # โค้ดบอร์ดควบคุม
├── arduino_2/
│   └── arduino_2.ino        # โค้ดบอร์ดจ่ายสินค้า
└── vending_machine/         # โปรแกรมบน Raspberry Pi
    ├── app.py               # เว็บเซิร์ฟเวอร์ Flask (Dashboard)
    ├── serial_reader.py     # รับ-ส่งข้อมูลกับบอร์ดควบคุมผ่าน Serial
    ├── database.py          # จัดการฐานข้อมูล SQLite
    ├── vending.db           # ไฟล์ฐานข้อมูล (สร้างเองอัตโนมัติถ้ายังไม่มี)
    └── templates/
        └── index.html       # หน้า Dashboard
```

## อุปกรณ์ที่ใช้

- Arduino UNO 2 บอร์ด
- Raspberry Pi
- จอ LCD 16x2 แบบ I2C (แอดเดรส `0x27`)
- เครื่องรับเหรียญ JY-100 (1 พัลส์ = 10 บาท)
- ปุ่มกด 6 ปุ่ม (A, B, C, D, ยกเลิก, ยืนยัน)
- เซอร์โวแบบหมุนต่อเนื่อง 4 ตัว (Continuous Rotation)
- เซนเซอร์ IR ตรวจจับสินค้าตก 1 ตัว

## การต่อขา

### บอร์ดควบคุม (arduino_1)

| ขา | ต่อกับ | หมายเหตุ |
| --- | --- | --- |
| D2 | สัญญาณเครื่องรับเหรียญ | Interrupt ขอบขาลง (FALLING) |
| D3 | TX ของบอร์ดจ่ายสินค้า (D1) | SoftwareSerial RX |
| D4 | RX ของบอร์ดจ่ายสินค้า (D0) | SoftwareSerial TX |
| D8, D9, D10, D11 | ปุ่ม A, B, C, D | `INPUT_PULLUP` กดแล้วขาจะเป็น LOW |
| D12 | ปุ่มยกเลิก | `INPUT_PULLUP` |
| D13 | ปุ่มยืนยัน | `INPUT_PULLUP` |
| A4 (SDA), A5 (SCL) | จอ LCD I2C | |
| USB | Raspberry Pi | Hardware Serial 9600 baud |

### บอร์ดจ่ายสินค้า (arduino_2)

| ขา | ต่อกับ | หมายเหตุ |
| --- | --- | --- |
| D0 (RX) | D4 ของบอร์ดควบคุม | Hardware Serial 9600 baud |
| D1 (TX) | D3 ของบอร์ดควบคุม | |
| D2 | สัญญาณเซนเซอร์ IR | Interrupt ขอบขาลง (FALLING) |
| A0, A1, A2, A3 | เซอร์โวช่อง A, B, C, D | |

> GND ของทั้งสองบอร์ดต้องต่อถึงกัน ไม่อย่างนั้นการสื่อสาร Serial จะเพี้ยน
>
> บอร์ดจ่ายสินค้าใช้ขา D0/D1 ในการสื่อสาร จึงต้อง**ถอดสายสองเส้นนี้ออกก่อนอัปโหลดโค้ด** แล้วค่อยต่อกลับ

## การติดตั้ง

### 1. อัปโหลดโค้ดลง Arduino

1. เปิด Arduino IDE แล้วติดตั้งไลบรารี `LiquidCrystal_I2C` (`Wire`, `SoftwareSerial` และ `Servo` มีมาให้แล้ว)
2. อัปโหลด `arduino_1/arduino_1.ino` ลงบอร์ดควบคุม
3. ถอดสาย D0/D1 ของบอร์ดจ่ายสินค้า แล้วอัปโหลด `arduino_2/arduino_2.ino` จากนั้นต่อสายกลับ


### 2. ติดตั้งโปรแกรมบน Raspberry Pi

```bash
pip install flask pyserial
```

ตรวจว่าบอร์ดควบคุมต่ออยู่ที่พอร์ตไหน

```bash
ls /dev/ttyUSB* /dev/ttyACM*
```

ถ้าพอร์ตไม่ใช่ `/dev/ttyUSB1` ให้แก้ค่า `SERIAL_PORT` ในไฟล์ `serial_reader.py`

### 3. รันระบบ

ต้องรันจากในโฟลเดอร์ `vending_machine` เพราะโค้ดเปิดไฟล์ `vending.db` จากโฟลเดอร์ที่รันอยู่

```bash
cd vending_machine
python3 app.py
```

จากนั้นเปิด Dashboard ด้วยเบราว์เซอร์ที่ `http://<IP ของ Pi>:5000`

พอเชื่อมต่อได้ Pi จะส่งราคาและสต็อกทั้งหมดไปให้บอร์ดควบคุมเอง และถ้าบอร์ดควบคุมรีเซ็ตแล้วส่ง `STATUS,ONLINE` มา Pi ก็จะส่งข้อมูลให้ใหม่อีกรอบ

## วิธีใช้งานตู้

1. หยอดเหรียญ เหรียญละ 10 บาท (หยอดได้หลายเหรียญ)
2. กดปุ่มเลือกสินค้า A, B, C หรือ D จอจะแสดงราคา
3. กดปุ่มยืนยัน ถ้าเงินพอ ตู้จะจ่ายสินค้า ถ้าเงินไม่พอ จอจะแจ้งว่าต้องใช้กี่บาท
4. ถ้าเปลี่ยนใจ กดปุ่มยกเลิกเพื่อล้างสินค้าที่เลือกไว้ (เงินที่หยอดแล้วยังอยู่ในระบบ)

ถ้าไม่มีใครใช้งานเกิน 30 วินาที ไฟจอจะดับ หยอดเหรียญหรือกดปุ่มใดก็ได้ จอจะกลับมาติด

## Dashboard

- ดูยอดขายรวม รายได้รวม และจำนวนที่ขายได้ของแต่ละช่อง (นับเฉพาะรายการที่สำเร็จ)
- ดูประวัติการขาย 20 รายการล่าสุด ทั้งที่สำเร็จและไม่สำเร็จ
- เพิ่ม ลด หรือตั้งค่าสต็อกของแต่ละช่อง ค่าใหม่จะถูกส่งไปที่บอร์ดควบคุมทันที

ฟอร์มแก้ราคาในหน้า Dashboard ถูกปิดไว้ (comment) และ `app.py` ยังไม่มี route `/update_price` ถ้าต้องการเปลี่ยนราคา ต้องแก้ในฐานข้อมูลโดยตรงแล้วรีสตาร์ต `app.py`

## โปรโตคอลการสื่อสาร

ทุกข้อความเป็นข้อความธรรมดา ความเร็ว 9600 baud และจบด้วยการขึ้นบรรทัดใหม่

| ทิศทาง | ข้อความ | ความหมาย |
| --- | --- | --- |
| บอร์ดควบคุม → Pi | `STATUS,ONLINE` | บอร์ดเพิ่งเปิดเครื่อง ขอข้อมูลราคาและสต็อก |
| Pi → บอร์ดควบคุม | `PRICE,A,10` | ตั้งราคาช่อง A (ต้องเป็นทวีคูณของ 10 และไม่ต่ำกว่า 10) |
| Pi → บอร์ดควบคุม | `STOCK,A,5` | ตั้งสต็อกช่อง A |
| บอร์ดควบคุม → Pi | `PRICE_UPDATED,A,10` / `STOCK_UPDATED,A,5` | ยืนยันว่าได้รับค่าแล้ว |
| บอร์ดควบคุม → บอร์ดจ่ายสินค้า | `A` ถึง `D` | สั่งจ่ายสินค้าช่องนั้น |
| บอร์ดจ่ายสินค้า → บอร์ดควบคุม | `Y` | IR พบสินค้าตก |
| บอร์ดจ่ายสินค้า → บอร์ดควบคุม | `N` | ครบ 15 วินาทีแล้วไม่พบสินค้าตก |
| บอร์ดควบคุม → Pi | `SALE,A,10,SUCCESS` | ขายสำเร็จ Pi จะบันทึกการขายและลดสต็อกลง 1 |
| บอร์ดควบคุม → Pi | `SALE,A,10,FAILED` | จ่ายไม่สำเร็จ Pi จะบันทึกการขายแต่ไม่ลดสต็อก และไม่มีการหักเงิน |

## การทำงานของบอร์ดจ่ายสินค้า

เมื่อได้รับคำสั่ง บอร์ดจะหมุนเซอร์โวของช่องนั้นเป็นจังหวะ คือหมุน 50 ms แล้วหยุด 150 ms วนไปเรื่อย ๆ ระหว่างนั้นคอยดูว่า IR พบสินค้าตกหรือยัง

- ถ้า IR พบสินค้าตก บอร์ดจะหยุดเซอร์โวทันทีแล้วตอบ `Y`
- ถ้าครบ 15 วินาที (`DISPENSE_TIMEOUT_MS`) แล้วยังไม่พบ บอร์ดจะหยุดเซอร์โวแล้วตอบ `N`

หลังตอบเสร็จ บอร์ดจะล้างข้อมูล Serial ที่ค้างอยู่ เพื่อไม่ให้รับคำสั่งซ้ำ

ค่าเหล่านี้ปรับได้ที่ส่วนบนของ `arduino_2.ino`

| ค่าคงที่ | ค่าปัจจุบัน | ความหมาย |
| --- | --- | --- |
| `FORWARD_A` ถึง `FORWARD_D` | 60 | ทิศและความเร็วในการหมุน (90 = หยุด) |
| `PULSE_ON_MS` | 50 | เวลาที่หมุนในแต่ละจังหวะ |
| `PULSE_OFF_MS` | 150 | เวลาที่หยุดในแต่ละจังหวะ |
| `DISPENSE_TIMEOUT_MS` | 15000 | เวลารอสูงสุดก่อนตอบ `N` |

## ฐานข้อมูล

`vending.db` เป็นไฟล์ SQLite มี 2 ตาราง

| ตาราง | คอลัมน์ |
| --- | --- |
| `products` | `product`, `price`, `stock` |
| `sales` | `id`, `product`, `price`, `status` (`SUCCESS` / `FAILED`), `created_at` |

ถ้ายังไม่มีไฟล์ฐานข้อมูล ระบบจะสร้างให้ตอนเริ่มรัน โดยตั้งค่าเริ่มต้นเป็น A = 10 บาท, B = 10 บาท, C = 20 บาท, D = 30 บาท และมีสต็อกช่องละ 10 ชิ้น

ถ้าต้องการเริ่มใหม่ทั้งหมด ให้ลบ `vending.db` แล้วรัน `app.py` อีกครั้ง (ประวัติการขายจะหายทั้งหมด)
